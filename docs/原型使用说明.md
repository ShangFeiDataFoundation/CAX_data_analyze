# CAX 工作区原型

## 启动

双击根目录的 `启动前端.cmd`，服务会自动打开浏览器。

也可以在 PowerShell 中运行：

```powershell
$env:PYTHONIOENCODING="utf-8"
python -m cax_pipeline.cli --serve
```

浏览器打开 `http://127.0.0.1:8200`。

## 使用流程

1. 点击“选择目录”，在系统文件管理器中选择本机已解压目录；也可以手动输入路径。
2. 在“API 配置”中填写 Base URL、模型和 API Key；也可以留空，使用本地 config。
3. 点击“扫描并解析”。
4. 扫描完成后输入“螺母”“六边形”“CFD”“液滴”等关键词搜索。

检索支持同义词组和部分关键词，例如输入单个“螺”也会扩展“螺母、螺帽、
六角螺母、nut、hex nut”等词并匹配六角螺母。

卡片会从统一 JSON 中提取关键指标：

- CAD：尺寸、体积、面/实体拓扑、孔或特征数量、形状标签。
- CAE：网格规模、结果场、分区、铺展系数、最大应力、最大位移等。

结果列表采用单列横向布局，左侧为渲染缩略图，右侧只展示名称、简短摘要、
少量标签和状态。完整指标、视觉画像及原始 JSON 在点击卡片后的详情弹窗中展示。

扫描产物写入 `data/frontend_runs/<run_id>/`，不会修改工作区中的源文件和已有 `json_out/` 产物。

## API Key

- 浏览器中输入 Key 时，是否缓存到 `localStorage` 由用户勾选。
- API Key 留空时，后端自动使用 `config.local.json` 或 `config.json` 中的配置。
- 建议把真实 Key 放在 `config.local.json`，不要把个人 Key 写入 `config.json`。

## 已有报告与导出

- 每个可解析 CAX 文件的报告保存在工作区的 `.cax_reports/records/<record_id>/`。
- 再次扫描同一目录时，会优先读取已有 `record.json`，不会重复调用视觉模型。
- 如果源文件大小或修改时间发生变化，记录会显示“已有报告 · 需更新”。
- 每个文件卡片都有“重新生成”和“导出”按钮；详情页也提供同样操作。
- 页面顶部的“导出报告”会生成 ZIP，包含 Markdown 汇总、每文件 JSON 和渲染图。
- 单文件导出的 ZIP 包含该文件的 Markdown、JSON 和渲染图。

## 数据分类

卡片显示数据分类概览。搜索区可以按“数据 / 元数据”层级以及几何、材料、网格、
结果场、质量等分类筛选。完整分类字段和来源标记在文件详情中查看，设计说明见
根目录 `CAX数据与元数据分类设计.md`。

## 性能分析

运行主界面默认只展示总耗时、成功率、LLM token、有效识别速率和缓存命中五项
关键指标。点击“性能详情”可查看阶段耗时、p50/p95、token 拆分、LLM 调用与降级、
非 LLM 吞吐、最慢操作和错误明细。性能明细可导出为 JSON/CSV，完整报告 ZIP
中包含 `performance.json` 和 `performance.md`。

## 扫描范围

- CAD：`.stp`、`.step`、`.igs`、`.iges`
- CAE：`.cas.h5 + .dat.h5`、`.cgns`、`.cgns.gz`、`.bdf`、`.nas`、`.dat`、`.op2`、`.op4`
- 不扫描压缩包内部；不跟随符号链接。
- Fluent 的 case/data 按同一目录自动配对。
